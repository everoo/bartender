# Bartender + Alexandria

> **Build the idea that helps and learns from every future idea.**

**Save time, over time.**

This is an early design for two connected projects:

- **Alexandria** aims to **deduplicate the internet**: preserve distinct, authorized knowledge, sources, failures, and discoveries while referring to truly repeated information instead of storing it twice.
- **Bartender** is a network of AI tools and workers that helps people and other AIs find, use, contribute to, and improve that knowledge. It aims to become the easiest and most efficient way to use Alexandria, without requiring exclusive access.

Together they aim to make accumulated knowledge useful without each intelligence having to rediscover it. The repository describes the idea; the working system has not yet been built.
